# Security Policy

Paperdian handles WeChat Official Account credentials, SSH key paths and runs a local Claude Code process. Please report vulnerabilities privately.

## Reporting

Use GitHub [private vulnerability reporting](https://github.com/KraussWang/paperdian/security/advisories/new). Do not open a public issue for security problems.

Never include real AppID/AppSecret, private keys, server addresses, `data.json` contents or tokens in a report. Redacted logs and reproduction steps are enough.

## Supported versions

Only the latest release receives security fixes.
