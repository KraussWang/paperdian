# 设置详解

## 本地 Claude Code

程序由用户安装与登录。插件启动本机 CLI，以当前 Vault 为工作目录，默认权限模式为 `acceptEdits`。可用性检查只验证程序能够返回版本，不发起模型请求，不证明账号已登录。默认模型留空时交给 Claude Code 决定。

## 专用 Skill 库

位置固定为 `<Vault>/.paperdian/skills/<Skill目录>/SKILL.md`，与插件安装目录分开。设置页支持打开目录、复制路径、安装两套内置示例。安装跳过任何已存在的同名目录，避免覆盖用户文件。

每轮只使用选择器中选中的 Skills；完整目录会复制到本轮临时目录，附属资源可用。修改后重新打开选择器刷新。

## 微信公众号与服务器

此模块是完整发布流程的必备组成部分。微信草稿创建必须具备以下配置：

| 项目 | 保存位置 | 操作 |
| --- | --- | --- |
| AppID、AppSecret | Obsidian SecretStorage | 遮蔽输入，点击保存生效；清除会把存储值设为空字符串，存储条目可能保留 |
| SSH 私钥正文 | 用户自行管理的本机文件 | 选择文件只获取路径，不读取或复制正文；运行时由 OpenSSH 使用 |
| SSH 主机、用户、端口和私钥路径 | 插件 `data.json` | 普通输入自动保存；端口必须为 1–65535 的整数 |
| 别名、默认作者、评论设置 | 插件 `data.json` | 用于本地回执及草稿生成 |

输入新的微信凭据后必须点击各自的“保存”。留空后保存不会删除已有值。输入框不回填已有凭据；关闭设置页会丢弃尚未保存的输入。Obsidian SecretStorage 由宿主管理，不能将其理解为插件自建的独立加密保险箱。

“测试服务器连接”只测试 SSH/网络出口；“验证微信凭据”才请求微信访问令牌，两者都不会创建草稿。验证成功不保证账号具有所有素材或草稿 API 权限，实际创建时仍可能返回权限错误。错误提示仅保留必要分类和微信数字错误码，不回显接口原始错误文本。

用户需自备服务器，不提供维护者的私人服务器地址和密钥。服务器公网出口必须在公众号 API 白名单内。没有配置微信时仍可编辑、使用 Claude 和本地预览；发布操作会要求补齐配置。

## 公开与分享

`data.json` 即使没有密钥正文，也有主机、账号和本机路径，不应上传。不要分享真实配置截图；微信输入框虽然遮蔽，其他输入项仍可能显示私人信息。仓库的 `examples/settings.example.json` 仅提供空普通配置，不用于导入微信凭据。
