# 人工验证清单

自动化测试覆盖模拟安装、设置页事件、凭据存储边界、SSH/微信 API 模拟和 Skill 安装；它们不等同于真实 Obsidian 与账号端到端验证。

使用测试 Vault 与自己的测试环境，记录操作系统、Obsidian、Claude Code 和插件版本。以下项目未执行前均标注“未验证”。

| 项目 | 操作与通过标准 |
| --- | --- |
| 设置页 | 三个区域完整显示；微信公众号与服务器为必备配置；首次安装无预填私人配置 |
| 凭据保存 | 输入不立即写入；点击保存后输入框清空且状态变成已保存；关闭重开不回显值；清除后状态为尚未设置 |
| 私钥选择 | 取消不改变旧路径；选择无扩展名密钥可获得绝对路径；私钥不被复制进插件目录 |
| Skill 库 | 打开和复制目录可用；首次安装两个示例；再次安装保留已有文件；选择器可见并能读取附属资源 |
| Claude | 版本检查可用；已登录账号完成首轮、续聊与取消；确认 Vault 文件生成符合预期 |
| 服务器 | 用自己的测试服务器完成连接检查；错误提示不暴露私钥内容或服务器地址 |
| 微信凭据 | 错误凭据显示失败和必要错误码；正确凭据通过；测试不创建草稿 |
| 文章草稿 | 标题、封面、图片、公式和主题预览正常；两篇文章可分别创建草稿；重复创建被阻止；微信后台内容正确 |
| 升级 | 只替换三个程序文件后原有设置、凭据、聊天、Skill 和回执仍可用 |

反馈仅使用脱敏信息，不上传真实配置、私钥、聊天或论文全文。
